# Notas de papers

Apuntes estructurados de artículos leídos durante el doctorado. Complementan `notes/analisis/` (hipótesis y experimentos propios) y el índice RAG (`phd-rag-docs`).

## Convención de nombres

`YYYY-MM-DD-<slug-autor-tema>.md`

Ejemplo: `2026-10-09-lonergan-normalizing-flows-subhalos.md`

## Qué incluir en cada nota

| Sección | Contenido |
| --- | --- |
| Metadatos | Autores, año, DOI/arXiv, enlace Zotero |
| Resumen en una frase | Idea central |
| Contexto / problema | Por qué importa |
| Métodos | Modelos, datos, algoritmos |
| Resultados clave | Cifras y figuras relevantes |
| Limitaciones | Lo que no cubre el trabajo |
| Conexión con la tesis | Artículo I / II / III del plan |
| Referencias cruzadas | Otros papers, código, issues |

Plantilla base: copiar desde `../_templates/nota.md` y ampliar con las secciones anteriores.

## Enlaces

- **Zotero:** clave de ítem (`item key`) o DOI en la cabecera de la nota.
- **Código citado en el paper:** URL y revisión git si la dan.
