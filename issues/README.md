# Specs de issues (SDD)

Especificaciones de desarrollo guiado por spec para tareas enlazadas a issues de GitHub en repos de investigación. El código vive en cada repo de producto; aquí solo la spec y el seguimiento.

## Layout

```text
issues/
  <nombre_repo>/
    <tarea>/
      spec.md
```

- **`<nombre_repo>`:** nombre corto del repositorio (p. ej. `density_field_properties`).
- **`<tarea>`:** slug estable, habitualmente `issue-<n>-<resumen-corto>`.

Añade en `spec.md` enlaces al issue de GitHub y, si aplica, notas de estado de implementación en el repo de producto.
